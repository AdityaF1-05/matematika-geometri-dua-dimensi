# SISTEM MATEMATIKA GEOMETRI 2 DIMENSI

Sistem ini bertujuan untuk menghitung luas dari bangun datar (fitur saat ini). Dengan menghitung bangun datar seperti bangun datar Segi Empat (fitur untuk saat ini yang masih tersedia). Dengan memberikan banyak pengamanan input yang lebih, dan fitur pilihan dan interaktif agar konsol terminal lebih hidup saat memilih kalkulasi geometri.

## FITUR

1. Menghitung sistem Geometri sederhana hingga menengah
2. Sistem interaktif pada konsol terminal
3. Pengamanan input agar mencegah kode error atau bug

## Cara Menjalankan Program

1. Unduh file Header dan semua file dengan ekstensi .cpp
2. Setelah diunduh, jangan menekan tombol run secara langsung (seperti Ctrl + Alt + N)
3. Gunakan command terminal dengan mengetik "g++ (nama file .cpp ditulis semua yang tersedia) -o program"
4. Setelah selesai dikompilasi dan tidak ada error, jalankan dengan perintah di terminal "./program"
5. Uji perhitungan, jika ingin selesai tekan 2 pada input main menu awal

- Contoh Kompilasi Terminal di Project ini : "g++ main.cpp geometri-2d.cpp -o program". tidak harus sama pemanggilan urutan file, setidaknya semua terkompilasi dan terdeteksi oleh kompiler

## Catatan !

Fitur akan ditambahkan lagi untuk kedepannya, jangan pernah mengecualikan file header. Dimana tugas file header ini adalah sebagai perantara fitur yang tersedia, untuk memisahkan sumber kode dengan fungsi fitur. Kalian bisa menambahkan fitur lagi di dalam satu file header yang sama, selama masih berkesinambungan fiturnya.
